# lunfit

Run tracking app with an AI coach.

| Directory | What it is |
| --- | --- |
| `lunfit-ui` | React Native (Expo) mobile client |
| `auth-service` | Java / Spring Boot — email auth, JWT, verification |
| `workout-service` | Java / Spring Boot — workouts and running metrics |
| `specs` | Feature specifications |

Each directory has its own README with setup instructions.
